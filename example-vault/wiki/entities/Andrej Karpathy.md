# Andrej Karpathy

## What it is
The author of [[LLM Wiki]], the idea file that describes a knowledge base an LLM builds and maintains. Other projects in this wiki name him as the origin of the pattern rather than as a maintainer of any implementation.

## Key facts
- Wrote the LLM Wiki idea file as a gist meant to be pasted into a coding agent, describing the pattern rather than an implementation.[^llm-wiki]
- The [[karpathy-llm-wiki]] skill calls itself an unofficial community implementation of the workflow from his idea and reproduces his tweet about it in its README.[^kw-readme]
- The skill's schema file opens with two core ideas attributed to him: "The LLM writes and maintains the wiki; the human reads and asks questions." and "The wiki is a persistent, compounding artifact."[^kw-skill]
