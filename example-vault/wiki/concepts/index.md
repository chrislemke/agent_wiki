# Concepts (5)

- [[Agent Skills]] — The open standard (agentskills.io) for packaging an agent's instructions as a SKILL.md file with supporting references and scripts, shared by Claude Code, Cursor, Codex CLI and OpenCode.
- [[Cascade Updates]] — The pass after a source's primary page is written in which every other page the source affects is found by searching the whole wiki and updated, with contradicted claims marked instead of rewritten.
- [[Grounding Invariant]] — The rule that every load-bearing number, date and quote in a wiki page exists verbatim in a raw source the page links, established when writing and verified by a script.
- [[LLM Wiki Pattern]] — A knowledge base that an LLM compiles and maintains as an interlinked markdown wiki from immutable raw sources, guided by a schema document, with ingest, query and lint as its operations.
- [[Open Knowledge Format]] — Google Cloud's open format for agent-maintained knowledge, markdown with YAML frontmatter fields for provenance, trust, freshness and lifecycle; the vocabulary this vault's frontmatter follows.
